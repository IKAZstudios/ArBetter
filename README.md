# Installation 
1. Download code as zip or clone.
2. Unzip the file.
3. Visit chrome://extensions or the equivalent for your browser (i.e. brave://extensions or vivaldi://extensions).
4. Enable "Developer mode".
5. Click "Load unpacked".
6. Select the folder you downloaded and unzipped.
7. Visit the arbor website and log in.

# Known Limitations (may be fixed in the future)
- Calendar only displays current day.
- Student name and profile not loaded.
- Actual notification content cannot be loaded, only the presence of notifications.
This is due to the way Arbor loads: this may be fixed at some point.
